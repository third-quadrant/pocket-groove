# Pocket Groove DAW 타임라인 설계

## 목표

기존 루프 기반 드럼 앱을 유지하면서, 실제 DAW처럼 보이고 조작되는 타임라인 중심 화면으로 확장한다. 트랙은 6개에 고정하지 않고 최대 32개까지 추가·삭제할 수 있다. 기존 `.mdrum` 파일은 열 수 있어야 한다.

## 확정된 범위

- 타임라인의 클립은 **하나의 루프 패턴이 반복되는 모습**을 트랙별로 보여준다.
- 하단 스텝 시퀀서는 선택한 트랙의 현재 루프 패턴을 편집한다.
- 여러 개의 서로 다른 패턴을 곡처럼 배치하는 곡 편곡 모드는 이번 범위가 아니다.

## 접근 방식 비교

1. **JavaFX 기본 컨트롤 확장** — 구현은 쉽지만 16분음표 그리드, 클립 미리보기, 재생선을 일반 컨트롤로 표현하면 관리 화면처럼 보인다.
2. **Canvas 기반 DAW 작업 화면** — 트랙 헤더와 타임라인, 스텝/벨로시티 그리드를 정밀하게 그릴 수 있다. 마우스·키보드 이벤트를 직접 다뤄야 하지만 밀도 높은 전문 음악 도구의 인상을 낼 수 있다.
3. **웹 기술 삽입** — 기존 JavaFX 앱과 실행·배포 구조가 갈라지고 외부 런타임이 추가된다.

**선택: 2번.** 화면은 JavaFX, 오디오는 기존 네이티브 엔진을 유지한다. 일반 버튼·저장·파일 선택은 검증된 JavaFX 컨트롤을 쓴다.

## 화면 구조

```
┌ 브랜드 · REC/PLAY/STOP · 마디.박.16분 · BPM · 4/4 · 루프 마디 · MASTER · PITCH · ⚙ ┐
├ 새 비트 · 열기 · 저장 │ 선택 트랙: 키 지정 · 소리 변경 │ +트랙 · -트랙 │ 줌 - + │ 입력 상태 ┤
├──────────────────────┬──────────────────────────────────────────────────────────────┤
│ 트랙 헤더             │ 마디 눈금 / 16분 그리드 / 패턴 클립 / 재생선                  │
│ 색 · 이름 · 단축키     │ 클립 안의 리듬 미리보기                                       │
│ (세로 스크롤)          │ (가로 스크롤·줌)                                              │
├──────────────────────┴──────────────────────────────────────────────────────────────┤
│ STEP SEQUENCER · 선택 트랙 · 현재 패턴 · 스텝 수                                     │
│ 16분 스텝 그리드 — 4박 강세, 활성/비활성, 선택 셀                                   │
│ Velocity 레인 — 활성 스텝의 세기                                                     │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

- 중앙 타임라인은 고정 폭 트랙 헤더와 스크롤되는 시간축을 한 캔버스에 그려 시각적으로 연결한다.
- 타임라인은 루프 길이의 네 배를 보여주며, 패턴 클립을 반복 배치한다. 루프 길이가 1마디면 4마디, 8마디면 32마디까지 가로로 이동한다.
- 트랙은 최대 32개이며 세로 스크롤한다. 선택 트랙은 lane 배경과 헤더에 동시에 강조한다.
- 스텝 시퀀서는 1마디=16스텝을 기본으로 하고, 루프가 2·4·8마디면 32·64·128스텝을 보여준다.
- 스텝 클릭은 해당 16분 음표 타격을 추가/제거한다. 드래그로 연속 칠하기, 스텝 영역 아래 벨로시티 레인 드래그로 세기를 조절한다.
- 재생선은 오디오 엔진의 박 위치를 사용한다. 클릭으로 재생 위치를 바꾸는 기능은 엔진에 탐색(seek)이 없으므로 넣지 않는다. 타임라인 클릭은 편집 커서만 옮긴다.

## 데이터·오디오 변경

- `Beat.Track`과 `Beat.Hit`을 가변 트랙 수로 바꾼다. 타격에는 `velocity`를 추가한다.
- 프로젝트 저장 버전을 2로 올린다. 1번 파일은 6트랙으로 읽고 velocity는 1.0으로 보정한다.
- 네이티브 믹서는 최대 32개 샘플 슬롯을 가지며, 재생 타격마다 velocity를 곱한다.
- 스텝 편집은 전체 사운드를 다시 디코딩하지 않고, 루프 이벤트만 오디오 엔진에 교체한다.
- 트랙 추가는 사운드 파일을 고른 뒤 새 트랙을 만들고 바로 키 지정으로 이어간다. 삭제는 해당 트랙의 타격을 함께 제거하며, 이후 트랙 인덱스를 당긴다.

## 키 입력 보강

일반 숫자 키 입력은 기존 테스트에서 동작한다. 다른 앱에는 숫자가 입력되므로 다음 경우를 함께 받는다.

- 숫자패드 `Numpad1`~`Numpad6`을 기본 숫자 `1`~`6`과 동일하게 처리
- 매크로 소프트웨어가 문자 이벤트로 주입하는 `KEY_TYPED`의 숫자·문자 처리
- 키 학습 중에도 동일한 별칭 규칙 적용
- 창 포커스 여부, 마지막 이벤트 종류, 코드/문자, 매칭된 트랙을 상단에 표시
- 일반 키보드에서 KEY_PRESSED와 KEY_TYPED가 중복 발음되지 않도록 짧은 중복 억제

입력 표시는 진단용이며 기존처럼 앱 창이 선택됐을 때만 연주한다.

## 시각 시스템

- 바탕 `#0F1114`, 패널 `#15181D`, 트랙 레인 `#1A1E24`, 상승면 `#20242B`
- 글자 `#E8EAF0`, 보조 `#8B929D`, 약한 선 `#262B33`, 강한 선 `#343B46`
- 액센트 `#E0A64E`, 녹음 `#CC5C4D`
- 트랙 색: 테라코타, 황토, 청록, 청회, 자주회, 올리브, 샌드. 채도를 낮춰 7색 이상은 순환·명도 변형.
- Barlow SemiBold로 숫자·영문 레이블, Nanum Gothic으로 한국어 본문. 이미 번들된 폰트를 재사용한다.
- 2px 이하의 각짐, 1px 구분선, 그림자 없음, 카드 레이아웃 없음.
- 모든 상태: 선택 트랙, 호버 lane, 선택 스텝, 활성 스텝, 벨로시티, 재생선, 키 학습, 파일 로딩 오류.

## 검증

- 모델: 가변 트랙/velocity/스텝 편집/트랙 삭제/기존 v1 프로젝트 로드.
- 입력: 숫자패드·KEY_TYPED·수정키 조합·중복 억제.
- 네이티브: 7개 이상 트랙, velocity 믹싱, 루프 이벤트 갱신.
- JavaFX: 트랙 7개 기본, 입력 학습, 녹음/재생, 스텝 편집, 1440×900과 좁은 창 캡처 검수.
- 패키징: 버전이 다른 폴더에 새 0.3.0 EXE와 런타임/네이티브 DLL/라이선스 포함. 실제 키 타건부터 DAC 출력까지의 지연은 별도 실측 없이는 수치를 주장하지 않는다.
