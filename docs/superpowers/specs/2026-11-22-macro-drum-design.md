# 6키 매크로 드럼 설계

## 목적과 범위
- Windows에서 Java와 JavaFX/CSS로 깔끔한 6패드 드럼 앱을 만든다.
- 기존 SDTech Options와 키보드 설정은 변경하지 않는다. 앱에 포커스가 있을 때만 키 입력을 받는다.
- 각 패드는 기본 드럼 소리를 제공하고 사용자가 오디오 파일과 단축키를 지정할 수 있다. 기본 소리는 사용 허가와 출처를 함께 기록한다.

## 접근 방식
- 선택: JavaFX의 일반 키 입력 이벤트를 사용한다. 기존 키 설정을 건드리지 않고 구현할 수 있지만 같은 키를 내는 일반 키보드도 반응한다.
- 대안: 장치를 직접 식별해 HID 입력을 받는다. 장치와 운영체제 지원 확인, 추가 구현이 필요하다. WebHID는 일반 키보드 입력을 제한할 수 있으므로 사용할 수 있다고 가정하지 않는다.
- 장치 직접 연결 가능성은 설치된 프로그램 및 장치 정보를 읽기 전용으로 조사한다. 기기에 설정 명령을 보내지 않는다.

## 화면과 동작
- 6개 패드마다 소리 이름과 지정 키를 표시하고 클릭이나 지정 키로 소리를 낸다. 패드에서 파일을 선택하고 키를 다시 지정할 수 있다.
- 녹음 시작부터 종료까지의 패드 입력과 시간을 기록한다. 종료 후 기록한 구간을 반복 재생하며 정지할 수 있다. 마이크나 시스템 전체 소리는 녹음하지 않는다.
- BPM을 조절하면 기록된 입력 간격과 반복 길이를 함께 조정한다. 피치는 샘플 재생 속도로 조절하므로 소리 길이도 달라진다.
- 만든 비트를 다시 불러올 수 있도록 입력 기록, 템포, 피치, 키 지정과 사용한 소리를 하나의 프로젝트 파일에 저장한다. 오디오 파일로 내보내기는 이번 범위에 포함하지 않는다.
- 동시에 여러 패드가 울릴 수 있어야 하며 파일 오류나 지원하지 않는 형식은 화면에 안내한다.

## 확인
- 키 지정, 녹음 타이밍, 반복과 템포 변환, 프로젝트 저장·불러오기를 검증한다.
- 실제 키보드의 입력 형태와 오디오 지연은 장치가 연결된 환경에서 확인한다. 기본 입력 방식은 장치별 구분을 보장하지 않는다.
