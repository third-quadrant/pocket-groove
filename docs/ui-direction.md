# Instrument surface — Operate

Code-led JavaFX desktop. Visual reference: `DESIGN.md`.

## Direction contract
THESIS: A compact DAW workspace where the looping drum pattern, not a set of cards, owns the screen. The timeline and step editor are the product.
OWN-WORLD: Charcoal ground, quiet panel shifts, fine grid lines, low-saturation track colors, amber transport accent. Barlow SemiBold and Nanum Gothic. Dense 52px track rows and a 16th-note editor.
STORY: Select a track, see its loop clip, tap or record the kit, refine rhythm and velocity, then save the whole project. The macro-keyboard configuration stays untouched.
FIRST VIEWPORT: Transport across the top, selected-track tools underneath, a full-width repeated-pattern timeline in the center, and a velocity-aware step sequencer at the bottom. The first track is selected; a playhead and edit cursor are visually distinct.
FORM: One-loop pattern repetition, chosen by the user over a multi-pattern song arrangement. seed:d4d605c7e9743535. The track names, colors and dark layout are specific to the drum machine, not a generic dashboard.
FINISH: unreviewed and undocumented is unfinished; this build ends with UI inspection at desktop and compact widths, the screenshots, and the implementation note.
