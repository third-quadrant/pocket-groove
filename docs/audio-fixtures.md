# Audio decoder test fixture

`src/test/resources/audio/cc0-toast.mp3` is a test-only sample from the PySoundTool format-test collection:

- Original file: `244287__kleinhirn2000__toast-glas-langsam.mp3`
- Source: https://github.com/a-n-rose/mini-audio-datasets/tree/master/test_audio
- The collection README says this sample was collected from Freesound under Creative Commons Zero (CC0): https://creativecommons.org/publicdomain/zero/1.0/
- It is used only to verify that the bundled JavaSound MP3 provider decodes MP3 to PCM. It is not included in the application or generated drum sounds.
