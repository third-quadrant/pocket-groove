# Pocket Groove visual system

Native JavaFX/CSS, single Operate surface. The six pads, rather than decorative chrome, carry its visual identity.

- Cool ground `#F3F5F8`, text `#30273F`, primary `#55436E`, controls panel `#EAE7F0`.
- Pad identity colors: peach `#F4B39E`, lilac `#C2B7DA`, mint `#AFD1C4`, gold `#E8CD83`, sky `#A9CADD`, rose `#D8B5CE`. The loop lanes repeat these identities; words and positions also distinguish pads.
- Barlow SemiBold (bundled OFL) for title, sound names and measurements. Nanum Gothic (bundled OFL) for Korean body text and controls. This replaces machine-dependent font assumptions.
- Three-column/two-row pad matrix, right transport column, bottom six-lane event tape. One vertical scroll region handles short windows. Window bounds are constrained to the current primary screen on startup.
- 34px title, 23px sound names, 21px section headings, 13px body. 14px pad radii, 8px action radii. Real focus outlines, disabled states, loading and file errors.
- Signature: a hit depresses and darkens its pad for 100ms; recorded hits land in the corresponding lane. No ambient animation.
- Implementation authority: `src/main/resources/drum.css`. Screenshots are generated by `DrumAppSmokeTest` into `target/screenshots/`.
