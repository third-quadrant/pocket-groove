# Pocket Groove
<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop (JavaFX; not a web surface).

## Stack
User-selected Java and JavaFX CSS. Self-contained Windows executable with a bundled redistributable runtime.

## Users and purpose
A six-key macro-keyboard owner wants to play drums, substitute audio, record and repeat beats, then save and reopen them.

## Constraints
Keep existing keyboard settings unchanged. Respond to keyboard input only while the app is focused. User approved ordinary key events rather than device-exclusive HID input. General keyboards with the same keys also work. Investigate SDTech WebHID read-only. Future GitHub distribution is intended; do not publish automatically.

## Brand commitments
Clean but distinctive UI. Exact palette and product name delegated to implementation.

## Scope approved
Six pads, audio replacement, tempo and pitch, recording pad events (not microphone), looping, portable project save/load. Pitch may change sample duration. Audio export is deferred.
